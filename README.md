# Campus Hub — ЦАТЭК

Демонстрационное приложение для студентов колледжа ЦАТЭК (Алматы), созданное на Expo SDK 57, React Native и TypeScript.

## Возможности

- Вход по четырёхзначному PIN и выбор одной из 12 учебных групп.
- Расписание с фильтрами по дням и неделям, заметками к занятиям.
- Новости колледжа и студенческие публикации в ленте в стиле Threads.
- Беседы учебных групп и личный кабинет.
- Светлое оформление с зелёным акцентом.
- Системная навигация iOS через Expo Router NativeTabs и SF Symbols. Liquid Glass отображается на поддерживаемой версии iOS.

## Запуск

```bash
npm ci
npx expo start
```

Откройте проект в Expo Go. Для подключения через интернет используйте `npx expo start --tunnel`.

## Проверки

```bash
npx tsc --noEmit
npx expo lint
npx expo export --platform ios
```

## Структура

`src/app` содержит маршруты Expo Router; `src/screens` — экраны; `src/components` — элементы интерфейса; `src/data/catecData.ts` — данные групп и колледжа; `src/services` — локальное хранилище и заготовку Supabase.

## Статус демонстрации

Посты, сообщения и профиль сохраняются на устройстве через AsyncStorage. Общая серверная лента пока не подключена. `supabase_schema.sql` и клиент Supabase — заготовки для дальнейшей интеграции. PIN демонстрирует сценарий входа и не заменяет серверную авторизацию. Вложения, QR и показатели профиля содержат демонстрационные элементы.

История Git начинается с импорта существующего проекта. Последующие коммиты отражают изменения при подготовке репозитория; ранее выполненные этапы описаны в CHANGELOG.md.
