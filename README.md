# Campus Hub — ЦАТЭК

Демонстрационное приложение для студентов колледжа ЦАТЭК (Алматы), созданное на Expo SDK 57, React Native и TypeScript.

## Возможности

- Вход по четырёхзначному PIN и выбор одной из 12 учебных групп.
- Расписание с фильтрами по дням и неделям, заметками к занятиям.
- Новости колледжа и студенческие публикации в ленте в стиле Threads.
- Пустой стартовый список чатов, создание личных чатов и бесед, добавление своей учебной группы.
- Главная с карточкой студенческого пропуска и демонстрационным QR над лентой.
- Профиль с обложкой, аватаром, данными студента и его публикациями.
- Свои фото из галереи для аватара, обложки и публикаций; локальное сохранение выбранных изображений.
- Белое оформление с голубым акцентом и системным шрифтом iOS (San Francisco).
- Системная навигация iOS через Expo Router NativeTabs и SF Symbols. Liquid Glass отображается на поддерживаемой версии iOS.

## Запуск

```bash
npm ci
npx expo start
```

Откройте проект в Expo Go. Для подключения через интернет используйте `npx expo start --tunnel`.

## Проверки


## Структура

`src/app` содержит маршруты Expo Router; `src/screens` — экраны; `src/components` — элементы интерфейса; `src/data/catecData.ts` — данные групп и колледжа; `src/services` — локальное хранилище и заготовку Supabase.

## Статус демонстрации

Посты, чаты, сообщения и профиль сохраняются на устройстве через AsyncStorage. Фото копируются в документы приложения. Общая серверная лента и переписка между устройствами пока не подключены. `supabase_schema.sql` и клиент Supabase — заготовки для дальнейшей интеграции. PIN демонстрирует сценарий входа и не заменяет серверную авторизацию. QR содержит демонстрационный ID и не открывает турникет. Файловые вложения и показатели профиля содержат демонстрационные элементы.

Отступы под статус-бар и системную навигацию задаются через safe area. Открытая беседа использует отдельный экран с фиксированной шапкой и областью сообщений, которая уменьшается при открытии клавиатуры. В веб-превью предусмотрен верхний отступ под имитацию Dynamic Island.
